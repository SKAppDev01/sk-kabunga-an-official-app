PHASE 13 — REPORTS PERMISSION SYNTAX FIX

ERROR FIXED

Unexpected token, expected ";"
src/services/reports.ts line 66

CAUSE

The previous role-permission patch inserted:

await requireOfficialAccess();

inside the TypeScript return type of getProjectsReport():

Promise<{
  await requireOfficialAccess();   <-- invalid
  rows: ...
}>

That is invalid TypeScript.

FIX

The permission check is now correctly inside the function body:

export async function getProjectsReport(): Promise<{
  rows: ProjectReportRow[];
  summary: ProjectsReportSummary;
}> {
  await requireOfficialAccess();
  await initializeDatabase();
  ...
}

The second report entry point, getGeneratedReport(), keeps its valid
service-layer permission check.

ONLY FILE CHANGED
src/services/reports.ts

No report calculations or report data were changed.
No role/security rules were removed.
